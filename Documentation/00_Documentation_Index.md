## Terminology

- **Quest:** a recorded work session.
- **Adventurer:** the local RPG identity attached to an authenticated Guild account.
- **Chronicle:** the finalized human-readable and machine-readable record of a Quest.
- **Guild:** the configured organization and its account authority model.
- **Quest Profile:** reusable session defaults and optional encounter configuration.
- **Quest Contract:** assignable work objective with project, reward, and completion context.
- **Focus Stage:** an ordered segment of a Quest with pace or reward effects.
- **Approved Break:** a configured, acknowledged break that is distinct from Focus, Meditation, and Idle/Unverified time.
- **External Activity:** evidence that a configured foreground creative tool was actively used; it does not create Focus time.
- **Shared Guild repository:** an optional folder-backed publication target for finalized records and public Adventurer snapshots.
- **Release blocker:** a failure that makes the package unsafe to ship or invalidates core records.
