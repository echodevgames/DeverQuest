## Identity and references

- [ ] Stable ID is unique and durable.
- [ ] Display name can change without breaking references.
- [ ] Required assets are assigned.
- [ ] No circular or missing references.
- [ ] Existing saved data migration considered.

## Rights and presentation

- [ ] Name/lore is original or licensed.
- [ ] Art/audio/font rights documented.
- [ ] Content is appropriate for intended audience.
- [ ] Demo/test content is clearly separated.

## Rules and balance

- [ ] Eligibility has positive and negative tests.
- [ ] Rewards cannot duplicate.
- [ ] Costs and loot reviewed.
- [ ] Typed combat expected values documented.
- [ ] Encumbrance/ownership/trade behavior tested.

## Chronicle and history

- [ ] Active Quest snapshot captures needed fields.
- [ ] Finalized record remains stable after asset edits.
- [ ] Human-readable output is understandable.
- [ ] Shared snapshot exposes only intended fields.

- [ ] Changes required
