# Guild Administrator Onboarding Checklist

## Identity and authority

- [ ] Founding CEO created and tested.
- [ ] Secondary administrator created.
- [ ] Boss permissions tested.
- [ ] Project Leader assigned to correct stable project.
- [ ] Member denial tests completed.
- [ ] Disabled-account process documented.
- [ ] Local audit trail reviewed.

## Storage

- [ ] Chronicle root selected and writable.
- [ ] Shared Guild repository protected and validated.
- [ ] Backup schedule active.
- [ ] Restore drill completed.
- [ ] Retention/deletion policy written.

## Policy

- [ ] Focus/idle settings approved.
- [ ] Wellness and Approved Break policy approved.
- [ ] Reward/economy values reviewed.
- [ ] External Activity providers approved.
- [ ] Shared ranking caps approved.
- [ ] Compensation Preview policy approved or disabled.
- [ ] Redemption approval/delivery process assigned.

## Content

- [ ] Empty studio structure generated.
- [ ] Demo content separated.
- [ ] Identity/Combat/Companion/Tactical catalogs reviewed.
- [ ] Audio/content rights confirmed.
- [ ] Stable ID policy documented.

## Support and release

- [ ] Support contacts published.
- [ ] Private security contact selected.
- [ ] License selected.
- [ ] Quest 1 completed.
- [ ] Release archive and checksum stored.
