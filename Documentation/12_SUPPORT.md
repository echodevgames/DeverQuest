## Information required for support

- DeverQuest package version;
- Unity editor version;
- operating system;
- installation type: tarball, embedded, Git URL, or registry;
- exact error or unexpected behavior;
- reproduction steps;
- whether a clean disposable project/profile reproduces it;
- relevant Console log;
- evidence files with personal/secrets removed;
- active Quest state and data-risk assessment.

## Support priorities

1. data loss, corruption, or false Focus;
2. unauthorized account/project actions;
3. duplicate rewards, ownership, trade, redemption, or publication;
4. install/compile failures;
5. unrecoverable active Quest;
6. layered/orphaned audio;
7. migration defects;
8. important workflow defects;
9. cosmetic/documentation issues.
